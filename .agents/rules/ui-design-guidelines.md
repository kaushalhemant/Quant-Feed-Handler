# UI Design System & Guidelines Rule

Always read `DESIGN.md` in the project root before changing or adding any UI, HTML, CSS, or frontend JavaScript components.

### Key Requirements:
1. Reference the design system stylesheet at `web/style.css` and use `:root` CSS variables.
2. Maintain high-contrast institutional dark theme and accessible colorblind theme support.
3. Use JetBrains Mono for numeric/tabular data and Outfit for headers.
4. Keep micro-animations hardware-accelerated.
